AWJ — Smart Study Planner
Project Description

AWJ is a client-side web application designed to help university students organize their academic life. The system allows users to manage courses, track deadlines, set weekly availability, generate personalized study plans, and monitor study progress in one platform.

Technologies Used
HTML5
CSS3
Vanilla JavaScript (ES6+)
localStorage
Gemini API
Features
User Registration & Login
Course Management
Deadline Tracking
Weekly Availability Scheduling
Auto-Generated Study Plans
Progress Tracking Dashboard
AI Study Tips Assistant
Dark / Light Mode

Installation Guide
Requirements
Visual Studio Code
Live Server extension
Modern browser (Chrome or Edge recommended)
Steps to Run the Project
Download or extract the project folder
Open the folder in Visual Studio Code
Open index.html
Right-click and choose "Open with Live Server"

No installation, server, or database setup is required.

Data Storage

All project data is stored locally using localStorage.
Each user's data is isolated using unique user IDs.

Environment Variables

The project uses a Gemini API key for AI-powered study assistance features.

For academic demonstration purposes, the API key is stored directly inside the JavaScript file.

Notes
Clearing browser storage resets saved data
The project runs entirely in the browser
